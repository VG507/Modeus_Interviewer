# Шаг 2. Данные и контракт первого интервью

Тема — диагностика медленного SQL-запроса для Python backend. Стартовое намерение — получить конкретный рабочий случай. Первый вопрос и два вручную сохранённых пересказа фрагментов выдачи hh.ru лежат в [данных темы](../data/interview/sql_topic.json). Ссылки ведут на страницы выдачи, которые могут меняться. Источники объясняют выбор темы. Факты о работе участника извлекаются из его ответов.

| Поле анкеты | Вопрос | Правило |
|---|---|---|
| `role` | Какая у вас роль? | Обязательно, до 200 символов |
| `experience` | Какой у вас опыт в этой роли? | Необязательно |
| `responsibilities` | За что вы отвечаете лично? | Необязательно |
| `conditions` | Какие условия работы важны для случая? | Необязательно |

Необязательные поля принимают пустую строку или до 1 000 символов. Ответ интервью содержит от 1 до 8 000 символов после удаления пробелов по краям. Анкета хранится снимком на сессии.

[Шесть синтетических сценариев](../data/interview/sql_scenarios.json) покрывают общий и подробный ответ, ответ «добавил индекс», неудачную попытку, отказ и неоднозначность. В каждом указаны известные факты, ожидаемое поведение и запрещённые домыслы. После реализации цикла проверяем смысл уточнения по этим критериям.

Контракт задан [схемами Pydantic](../backend/interview_schemas.py) и [примером первого хода](../data/interview/first_turn.json). Правила версий, прав и повторов приведены в [общем контракте](../Modeus_MVP_Technical_Contract.md).

| Операция | Схема запроса | Схема ответа |
|---|---|---|
| Создать интервью | `CreateInterview` | `201 InterviewView` |
| Получить интервью | — | `200 InterviewDetail`, сообщения по `sequence` |
| Сохранить ответ | `CreateAnswer` | `201 AnswerResult` со статусом ответа `draft` |
| Изменить черновик | `UpdateAnswer` | `200 AnswerResult` |
| Отправить черновик | `VersionedRequest` | `202 AnswerResult` со статусом ответа `queued` |
| Пропустить, завершить, повторить | `VersionedRequest` | `202 InterviewView` |
| Ошибка | — | `ErrorResponse` |

Сервер сверяет, что вопрос текущий, ответ относится к нему, а ссылки извлечения ведут на отправленные ответы той же сессии. После обработки frontend получает сохранённый вопрос чтением интервью. Токены заданий, владелец и сырой результат модели остаются в backend. Храним время как UTC и отдаём его с суффиксом `Z`.

Миграция `0002` добавляет темы, источники, сессии и сообщения. Обработчик заданий и хранение ключей идемпотентности добавляются вместе с транзакциями цикла на шаге 3. Карточки получат свою миграцию при подключении синтеза.

```powershell
.venv/Scripts/python.exe -m alembic upgrade head
.venv/Scripts/python.exe -m scripts.seed_interview
.venv/Scripts/python.exe -m alembic check
.venv/Scripts/python.exe -m pytest -q
```

Начальные данные можно загрузить повторно. Команда обновляет записи по тем же ID. Ключ hh.ru для ручных данных не нужен.
